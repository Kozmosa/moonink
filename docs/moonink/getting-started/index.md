如果你是第一次接触 MoonInk，从这里开始最省路径。这个 section 只关注“先把站点跑起来”，把更细的概念说明留给 [[content-model]]、[[config]] 和 [[frontmatter]]。

## 推荐顺序

1. [[install]]
2. [[first-site]]
3. [[check-and-serve]]

## 你会得到什么

- 一个独立的 `moonink.json`
- 一个可以 `build` 的最小站点
- 对 `check`、`build`、`serve` 各自边界的基本理解

- 普通目录：看 [从 Markdown Folder 接入](../migration/from-markdown-folder.md)
- Obsidian Vault：看 [Obsidian Vault 指南](../guide/obsidian-vault.md)
