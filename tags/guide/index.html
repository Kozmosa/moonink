  • CLI 命令

    MoonInk 当前对外的命令面很小，核心就是 help、onboard、build、check、serve 五个命令。

  • 配置文件

    MoonInk 使用一个项目根级别的 moonink.json，内容不多，但会决定内容根、输出目录、route 风格和主题路径。

  • Theme V2

    Theme V2 是当前推荐的主题 authoring path；如果你暂时不自定义主题，MoonInk 会使用 built-in default theme。

  • 页面元数据

    MoonInk 的 frontmatter 以内容作者真正会用到的字段为主，先掌握 title、summary、tags、draft 和 type 就已经足够高频。

  • 内容模型

    MoonInk 主要处理 article 与 page 两类内容，同时支持根首页推断、HTML page 和 Vault 风格的 README fallback。

  • Obsidian Vault

    MoonInk 可以直接接入 Obsidian Vault：保留 README 首页、附件资源和 WikiLink 写法，不必先把内容改造成另一套结构。

  • 检查与预览

    check 用来提前暴露问题，serve 用来本地预览；它们的职责不同，而且 serve 明确是 native-only。

  • 链接与资源

    MoonInk 支持普通 Markdown 内链、WikiLink、带 label 的 WikiLink、资源型 WikiLink 和图片 embed。

  • 路由与输出

    MoonInk 目前支持 pretty 和 direct 两种 route style，它们决定了 URL 形态，也决定了 dist 目录的组织方式。
