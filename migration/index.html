迁移与接入

MoonInk 的推荐迁移方式不是一次性重写所有页面，而是先让现有内容被 check 和 build 接受，再逐步优化结构与主题。

两条接入路径

  • 从 Markdown Folder 接入

  • 从 Obsidian Vault 接入

迁移时最值得保留的习惯

  • 先 check 再 build
  • 优先让首页和内部链接稳定下来
  • 最后再处理 Theme V2、自定义 wording 和结构细化
