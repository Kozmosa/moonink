快速开始

如果你是第一次接触 MoonInk，从这里开始最省路径。这个 section 只关注“先把站点跑起来”，把更细的概念说明留给 content-model、config 和 frontmatter。

推荐顺序

  1. install

  2. first-site

  3. check-and-serve

你会得到什么

  • 一个独立的 moonink.json

  • 一个可以 build 的最小站点

  • 对 check、build、serve 各自边界的基本理解

从现有内容开始

如果你不是新建站点，而是准备接入已有内容：

  • 普通目录：看 从 Markdown Folder 接入
  • Obsidian Vault：看 Obsidian Vault 指南
